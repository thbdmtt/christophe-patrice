# Présentation commerciale

Livrables :

- `output/Proposition-site-Christophe-Patrice.pptx` : version PowerPoint éditable, avec notes d’orateur.
- `output/Proposition-site-Christophe-Patrice.pdf` : version prête à envoyer ou à consulter sans PowerPoint.
- `output/previews/` : aperçu PNG de chaque diapositive et vue d’ensemble.

La présentation suit un fil en sept temps : vision, avant/après, parcours utiles, enjeu numérique, validation des informations, proposition d’échange et déroulé de mise en ligne.

Le fichier `build-slides.cjs` permet de régénérer le PowerPoint avec Node.js et `pptxgenjs`.
